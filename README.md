# Vale das Frutas: beta para a escola

Só a tela de histórias e os 3 minigames. Sem login, sem Firebase e sem nada salvo.

## Publicar no Vercel

1. No Vercel, crie um projeto novo (Add New > Project) a partir desta pasta.
2. O Vercel reconhece o Vite sozinho (`npm run build`, pasta `dist`).

## Rodar no computador

    npm install
    npm run dev
